# 来源与公开变更

## 快照来源

EFI 来源为本机可读取的 FAT 卷中的 `EFI` 目录。其 `OC/config.plist` 与 2026-10-10 12:44 的驱动升级预检备份逐字节一致。

这只能确认两个配置文件一致，不能单独证明该卷就是当前启动使用的内置 ESP。本次工具环境无法使用 DiskManagement 完成当前启动分区识别，所以不把来源描述成已重新核实的内置启动 EFI。

安装后硬件状态来自本机检查记录，并以本次 system_profiler 的 CPU 类别、RTX 3060、内存和 macOS 构建信息补充核对。CPU 的具体 i5-11400F 型号同时出现在安装后记录和原 EFI 的 CPU 名称变量中。主板商品型号与无线模块商品型号未可靠确认。

## 脱敏与改动

- `PlatformInfo/Generic/MLB` 和 `SystemSerialNumber` 清空。
- `SystemUUID` 使用全零占位，`ROM` 使用 6 字节全零占位。
- 对全部 plist 进行递归检查，清空 Wi-Fi SSID、密码及其他机器身份字段。
- 原有 `config.plist.nullmoth-*` 备份、日志、隐藏文件和其他非 EFI 白名单目录不进入公开版本。
- `NullMothSafe.efi` 文件保持原样，但 `Misc/Tools` 中对应入口改为禁用，因为不能转移本机恢复服务和备份依赖。
- 其余配置、ACPI、驱动二进制与资源按原快照保留；plist 经标准解析器重新序列化，格式变化不应视为功能调整。
- 原始系统报告、EDID 原始块、私人恢复脚本、NVRAM 导出、个人日志和系统显卡驱动包未公开。

## 核验与限制

发布准备过程中，对所有 plist、ACPI、驱动和工具引用做结构与存在性检查，对整个 EFI 生成 SHA-256 清单，并扫描原身份值在 UTF-8、UTF-16 与原始字节中的残留。

没有在本次发布整理期间切换刷新率、升级驱动、修改实际启动 EFI 或重启电脑。原 OpenCore 版本未可靠确认，没有完成匹配版本的 `ocvalidate`，也没有对脱敏占位版本执行启动测试。

可复现性仍取决于使用者自己的硬件、BIOS、身份信息、USB 映射和系统显卡驱动安装。后续补充主板与无线型号时，应基于真实硬件报告更新。
